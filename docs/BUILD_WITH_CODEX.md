# AGENTS.md와 데이터로 직접 개발하기

완성된 소스를 실행하는 대신, Codex와 대화하면서 자신의 앱을 만들어 보는 방법입니다. 기존 예제의 DB나 입력 완료 기록은 필요하지 않습니다.

## 1. 지침과 데이터 준비

저장소를 다운로드한 폴더에서 다음 명령으로 UCI 원본을 준비합니다. Python 3.11 이상이 필요합니다. 직접 [UCI 사이트](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)에서 받아도 됩니다.

```powershell
python scripts/download_data.py
```

새로운 빈 작업 폴더를 만들고 다음 두 가지를 복사합니다.

```text
새_작업_폴더/
  AGENTS.md
  data/
    household_power_consumption.txt
```

- `AGENTS.md`: Codex가 지킬 개발 원칙과 진행 순서입니다.
- 원본 데이터: 분석할 실제 자료입니다. 수정하지 않고 보존하도록 요청합니다.

완성 예제의 `server/`, `web/`, `runtime/`, DB 파일이나 개발 당시 설정을 복사할 필요는 없습니다. 새 폴더에서 자신의 요구사항과 코드를 새로 만들어 갑니다.

## 2. 실행 환경 준비

Codex와 Machbase Neo를 사용할 수 있어야 합니다. Neo를 설치하고 실행한 뒤 실제 실행 파일 경로와 접속 포트를 확인합니다. 이 예제의 기본 포트는 Neo HTTP `5654`, DB Native `5656`입니다.

새 작업 폴더를 Codex에서 엽니다. 완성 예제 폴더 대신 앞에서 두 자료를 준비한 새 폴더를 선택합니다.

## 3. 만들 앱 설명하기

다음은 설명 예시입니다. `<NEO_DIR>`은 자신의 설치 폴더로 바꾸고, 화면이나 기능은 원하는 내용으로 바꿉니다.

```text
공개 가정용 전력 데이터로 Energy Peak Explorer라는 작은 웹 앱을 만들고 싶어.
data 폴더의 원본은 보존하고 전체 자료를 내 Machbase DB에 저장해줘.

첫 화면에는 살펴보기 좋은 한 달을 골라 보여 줘.
날짜를 바꾸면 총 사용량, 최대 분 평균 전력과 발생 시각,
시간별·일별 그래프가 함께 바뀌면 좋겠어.
조회 범위는 최대 달력 기준 한 달로 해줘.
평소보다 높은 사용량 구간과 그래프에서 고른 시점의 상세값도 보여 줘.
검은색과 오렌지색 화면을 원해.

Machbase Neo 실행 파일은 <NEO_DIR>\machbase-neo.exe이고,
HTTP 포트는 5654, DB Native 포트는 5656이야.
서버는 JSH로 작성해줘.

먼저 요구사항과 개발 계획만 정리해줘.
내가 검토한 뒤 개발 시작을 요청할게.
```

Codex는 `APP_REQUEST.md`와 계획을 정리합니다. 날짜 범위, 결측 처리, ‘평소보다 높음’의 의미 등을 읽고 자신의 의도와 맞는지 확인합니다. 기술 선택을 모르면 조사한 권장안을 설명해 달라고 요청하면 됩니다.

## 4. 계획 검토와 개발 요청

수정할 부분을 대화로 전달합니다. 예를 들어 다음처럼 요청할 수 있습니다.

```text
높은 사용량의 기준을 과거 같은 시간대 평균의 1.7배 초과로 해줘.
요구사항과 계획에 함께 반영해줘.
```

계획이 맞으면 `계획대로 개발을 시작해`라고 요청합니다. DB 비밀번호는 공개 소스나 채팅에 적는 대신, 안내받은 서버 측 비공개 설정에 직접 입력합니다.

이 과정에서 Codex가 자신의 환경에 맞는 테이블 생성·데이터 입력·검증·앱 실행 방법을 만들도록 합니다. 이 저장소의 과거 적재 완료 기록을 사용하면 안 됩니다.

## 5. 결과 확인

개발이 끝나면 다음을 확인합니다.

- 자신의 DB에 전체 자료가 입력됐고 원본 계산과 일치하는가?
- 기간을 바꾸면 숫자와 그래프가 함께 바뀌는가?
- 최대값과 시각, 결측, 높은 사용량 구간이 설명한 기준에 맞는가?
- 그래프 선택과 상세값 조회가 동작하는가?
- 자신의 PC에서 실행·접속·종료하는 명령이 README에 있는가?

원하는 부분을 구체적으로 짚어 수정 요청하고 다시 확인합니다. 다른 센서나 시계열 자료에도 AGENTS.md를 새 작업 폴더에 복사해 같은 과정을 사용할 수 있습니다.

직접 개발 대신 제공된 앱을 바로 실행하려면 [README의 완성된 앱 실행 절차](../README.md#완성된-앱-실행하기)를 따릅니다. 이 경우 Codex는 필요하지 않으며 자신의 DB에 입력하는 프로그램이 이미 제공됩니다.
